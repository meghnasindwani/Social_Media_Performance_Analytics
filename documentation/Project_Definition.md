# Social Media Performance Analytics & Recommendation System

## 1. Problem Statement

How can publicly available social media data be analysed
to identify content performance patterns and generate
evidence-based recommendations for improving content strategy?

## 2. Project Objectives

1. Analyse social media content performance.
2. Identify relationships between content characteristics
   and engagement metrics.
3. Analyse content formats and categories.
4. Study audience discovery and interaction patterns.
5. Apply statistical techniques to validate observations.
6. Develop suitable machine learning models where feasible.
7. Build an evidence-based recommendation engine.
8. Develop a Power BI dashboard.
9. Develop a Streamlit application.

## 3. Project Scope

The project will use publicly available social media datasets.
It will focus on data preprocessing, database development,
analytics, statistical analysis, machine learning where feasible,
recommendations and interactive reporting.

## 4. Expected Outcomes

- Cleaned datasets
- PostgreSQL database
- SQL analytical queries
- EDA and statistical analysis
- Evaluated ML models, if feasible
- Recommendation engine
- Power BI dashboard
- Streamlit application
